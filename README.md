# ML Algorithm Playground

A collection of machine learning algorithms implemented and explored in Python. This repository focuses on understanding the fundamentals of machine learning through hands-on experiments, data analysis, and model evaluation.

## Topics

- **Linear Regression** — Model training, coefficient estimation, least-squares methods, and RMSE evaluation.
- **Classification** — Multi-layer perceptrons (MLPs), hyperparameter tuning, and accuracy evaluation.
- **Clustering** — K-means clustering, centroid-based error measurement, and cluster evaluation.
- **Reinforcement Learning** — Policy iteration in Gridworld and Deep Q-Networks (DQN).

## Technologies

- Python
- NumPy
- Matplotlib
- Pandas
- Scikit-learn
- PyTorch
